## 联调环境

- 后端启动：`.venv/Scripts/python.exe -m uvicorn app.main:app --reload`（默认 127.0.0.1:8000，SQLite 自动建库播种）
- 前端地址：`entry/src/main/ets/common/Config.ets` 的 `ApiConfig.BASE_URL`
  - DevEco 模拟器：`http://10.0.2.2:8000/api/v1`（当前值）
  - 真机：改宿主机局域网 IP + 后端 `--host 0.0.0.0` + 防火墙放行
- **账号库切换提示**：认证后端化后，模拟器里旧本地账号作废，需在 App 中重新注册一次。

## 已知差异与裁决记录

1. `logout`：后端 JWT 无状态，无 `/auth/logout` 端点；前端 logout 清端侧 token 即生效。若未来要求强制吊销，再加会话黑名单（届时先改契约）。
2. `finishOrder(orderId, data)` 的 `data` 参数仅为兼容旧签名保留，**结算数值以服务端为准**（防止端侧篡改金额）。
3. 展示元数据（停车位号/楼层/收费方式/电话/标签/地图坐标）留在前端 `MockData.ets`（契约 §10 决策 1），与后端种子 id/code 对齐维护。
4. 时间口径：后端 naive UTC 存储、出口 `YYYY-MM-DD HH:MM:SS`（`fmt_datetime`），与前端展示格式一致。
